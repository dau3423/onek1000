# 조사 보고: 독립 셀프세차장·손세차장 지도 표시 — 활용 가능한 데이터 소스

> 담당: researcher (주제 지정 모드, 2026-08-16). 코드 수정 없음.
> 배경: 진행 중 사이클(2026-08-16-new-feature-discovery)의 C2는 주유소 `has_carwash`(부설 세차장)만 다룬다.
> 본 조사는 **독립 세차장(셀프/손세차/자동·노터치)을 별도 지도 레이어로 표시할 데이터 소스**를 검증한다.
> 모든 주장에 출처(파일 경로/URL)를 달았고, 추측은 "가설"로 표시했다.

## 0. 결론 요약 (PM용)

- **1안(추천): 행정안전부 「전국세차장표준데이터」 파일 임포트.** 실제 CSV를 내려받아 검증했다 — **16,186행, WGS84 위도/경도 100% 채움, `세차유형`·`사업장업종명` 필드 보유, 이용허락 제한 없음(무료)**. EV 레이어(sync-ev) 패턴을 거의 그대로 재사용해 1사이클 내 구현 가능.
- **카카오 로컬 API로 자체 DB 구축은 약관 위반**(공식 답변: "Live call only", 캐싱·저장 금지) — 주 소스로 부적합. 단, "저장 없는 실시간 검색 보조"로는 사용 가능.
- **대안: 크라우드소싱 보정 레이어** — 공공데이터의 약점(세차유형 62% 미기재, 폐업 여부 불명)을 사용자 제보로 보정. 단독 소스로는 불가(DAU 규모), 1안의 후속 보강으로만.

## 2. 문제/기회 (사용자 관점)

- 세차는 전 운전자의 반복 니즈지만, 주유소 부설 세차(자동/기계식 위주)와 **셀프세차장·손세차·디테일링은 다른 사용 목적**이다. 부설 플래그만으로는 "근처 셀프세차장 어디?"에 답할 수 없다.
- 니즈 실증: 전국 세차장 비교 서비스 "워시랩"이 독립 존재(전국 4,256곳 — 셀프 1,432/자동 1,321/손세차 2,282/주유소 세차 147/24시간 152 분류 제공). 커뮤니티 질문("서초강남권 셀프 세차장 어디?")도 상시 존재.
  - https://washlab.product-pack.com/area/gyeonggi-pyeongtaeksi-죽백동-underbody-carwash/ , https://www.clien.net/service/board/cm_car/19158559
- 기회: 주유(최저가) → 세차(부설+독립)를 한 지도에서 잇는 국내 주유 앱은 없음(가설 — 오일나우·티맵에서 독립 세차장 레이어 미확인). 공공데이터 기준 1.6만 곳은 워시랩(4,256곳)의 약 4배 커버리지.

## 3. 외부 소스 조사 결과

### 3.1 공공데이터: 행정안전부 「전국세차장표준데이터」 — ★ 주 소스로 적합

- 데이터셋 페이지: https://www.data.go.kr/data/15013193/standard.do
  - 파일명 `행정안전부_세차장정보_20251127`, 갱신 "수시(2일전 기준 현행화)", **이용허락범위 제한 없음, 무료**, 소관 기후에너지환경부(물환경보전법상 폐수배출시설 인허가 기반).
- **실측 검증(2026-08-16, CSV 직접 다운로드·파싱)** — 다운로드 엔드포인트 `https://file.localdata.go.kr/file/download/car_wash_info/info` (안내 페이지: `https://file.localdata.go.kr/file/car_wash_info/info`):
  - **16,186행 / 24컬럼**. 컬럼: 개방자치단체코드, 관리번호, 사업장명, 시도명, 시군구명, **사업장업종명**, **세차유형**, 소재지도로명주소, 소재지지번주소, 휴무일, 평일/휴일운영시작·종료시각, **세차요금정보**, 대표자명, 세차장전화번호, 수질허가번호, **WGS84위도, WGS84경도**, 데이터기준일자, 데이터갱신구분, 데이터갱신시점, 최종수정시점.
  - **좌표: WGS84 위경도 99.96% 채움(16,179/16,186)** — EPSG 변환 불필요, PostGIS에 바로 적재 가능.
  - **셀프/손세차 구분 가능성**: `세차유형` 자유입력 — 채움 38%(미기재 10,079행). 기재분: 손세차 1,640 / 자동세차 1,409 / 자동차세차 1,200 / 셀프세차·셀프 508+ / 기계식 등 다수 변형. 보조 휴리스틱: 사업장명에 '셀프' 포함 1,449행(9.0%), '손세차/디테일' 739행 → **유형+상호 키워드 결합으로 self/hand/auto/unknown 4분류 정규화 가능**.
  - **독립 vs 부설 구분 가능**: `사업장업종명`에 '세차' 포함(독립 추정) 10,838행, '주유·충전' 포함(부설 추정) 4,344행 → 부설 행은 기존 `has_carwash`와 중복되므로 제외/병합 정책 선택 가능.
  - 전국 커버리지: 시도 16개 전부 포함(경기 4,545 ~ 세종 91. '전남광주통합특별시' 등 2026 행정구역 개편 명칭 사용 — 우리 `sido` 체계와 매핑 필요).
  - 부가정보 채움률: 운영시각 10.1%, 세차요금 5.5% — 표시하되 기대치 낮게.
  - `데이터갱신구분` I 12,993 / 빈값 3,020 / U 173 (D 없음). **영업상태(폐업) 컬럼 자체가 없음** — "영업 중만 수록" 여부는 미확인(가설, §6).
- OpenAPI는 없고 파일 다운로드만 제공(페이지 실측 — API 탭 부재). 다운로드는 Referer 헤더 없이 403(실측) → sync 코드에서 헤더 지정 필요.
- 참고: 원천인 지방행정인허가(localdata.go.kr) 포털은 2026-04-16 폐쇄되어 data.go.kr로 이관됨(웹 접속 실측: `www.localdata.go.kr` 연결 거부, 파일서버 `file.localdata.go.kr`는 동작). 출처: https://github.com/NomaDamas/k-skill/blob/main/docs/features/localdata-business-status.md

### 3.2 카카오 로컬 API — 주 소스 부적합(약관), 보조로만

- 카테고리 그룹 코드 19종에 **세차장 없음**(OL7=주유소·충전소가 최근접) → 키워드 검색("세차장")만 가능. 키워드 검색은 페이지당 최대 15건 × 45페이지 = 쿼리당 675건 상한이라 전국 수집엔 격자 분할 크롤이 필요.
  - https://developers.kakao.com/docs/latest/ko/local/dev-guide
- **약관 리스크(결정적)**: 카카오 공식 답변 — 로컬 API는 "실시간 호출(Live call)만 가능", 결과의 서버 캐싱·DB 저장은 운영정책 제5조 20호 위반("사용자 환경 개선 목적 외 캐시" 금지). 1시간 캐시조차 불허 판정.
  - https://devtalk.kakao.com/t/api/150800 (카카오 공식 답변), https://devtalk.kakao.com/t/api/140197
- **허용되는 활용**: 사용자가 지도에서 세차장을 즉석 검색 → 결과를 저장 없이 즉시 표시(우리는 카카오맵 SDK 사용 중이라 지도 결합 제약도 없음). 즉 "우리 DB 레이어의 갭을 메우는 실시간 보조 검색"으로는 합법적 사용 가능.

### 3.3 네이버 지역검색 API — 부적합

- `display` 최대 5건/쿼리(트래픽 제한) → 지도 레이어용 대량 수집 자체가 불가능. 좌표는 KATECH계 mapx/mapy로 변환도 필요.
  - https://velog.io/@cyseok123/Spring-네이버-지역-검색-API-사용하기 (display 5 제한), 공식: https://developers.naver.com/docs/serviceapi/search/local/local.md (WebFetch 차단으로 문서 원문 직접 확인은 못함 — 가설 아님, 다수 구현 사례로 교차 확인)

### 3.4 세차 프랜차이즈 공개 지점 정보 — 부적합

- 워시존(washzone.co.kr)·워시랜드(washland.co.kr) 등은 세차기 제조·창업 브랜드 성격이 강하고, 통합 전국 지점 목록·좌표를 구조적으로 공개하지 않는다(검색 실측 — 매장 수조차 확인 불가). 브랜드별 스크래핑 대비 얻는 커버리지가 공공데이터(1.6만)의 극히 일부라 비용 대비 무가치.
  - https://www.washzone.co.kr/ , http://www.washland.co.kr/

### 3.5 크라우드소싱(사용자 제보) — 단독 불가, 보정용

- 현 DAU ~150 규모(진행 사이클 research.md §C6 근거)에서 전국 1.6만 곳을 제보로 채우는 것은 비현실적. 다만 공공데이터의 약점인 **세차유형 미기재(62%)·폐업 미반영**을 "유형 제보/폐업 신고" 1탭 UI로 보정하는 하이브리드는 현실적(리뷰·rate limit 인프라 재사용, `supabase/migrations/0004_reviews.sql` 전례).

## 5. 개선 방향 제안

### 1안(추천): 전국세차장표준데이터 임포트 → `carwash` 지도 레이어
- **내용**: ① `carwash_places` 테이블(0011 EV 스키마 축소판: id=관리번호, name, 유형(enum self/hand/auto/unknown), 주소, tel, 운영시각·요금·휴무일(있으면), lat/lng+geom GiST, 사업장업종명 원문, synced_at) ② `app/api/internal/sync-carwash`(CRON 주 1회면 충분 — 원천이 "수시" 갱신이므로. CSV 1파일 3.6MB·1.6만행, Referer 헤더+cp949 디코딩 필요, EV처럼 청크 upsert) ③ `rpc_carwash_by_bbox` + `app/api/carwash/bbox`(EV bbox 49줄 복제 수준) ④ `MapLayer`에 `'carwash'` 추가 + FilterBar 칩 + 팝업(EvStationPopup 패턴) + 유형 필터(셀프/손세차/자동/전체).
- **기대 효과**: "주유+세차" 결합 국내 유일 포지션, 진행 사이클 C2(세차 지수)와 시너지 — 세차하기 좋은 날 → 근처 셀프세차장 딥링크. 신규 검색 유입 소재("OO동 셀프세차장" 롱테일 — /regions 허브 전례, 커밋 `e824f69`).
- **예상 비용**: 1사이클(마이그레이션+sync+bbox는 반나절, 레이어 UI 반나절). 외부 키 불필요(무인증 파일 다운로드)라 EV보다 오히려 단순.
- **주의**: 대표자명 컬럼은 개인정보 최소화 원칙상 **임포트 제외**. 부설(주유·충전 업종) 행은 기존 has_carwash와 중복 — v1은 독립 세차장만 임포트 권장.

### 2안(1안의 후속 보강): 유형·폐업 크라우드소싱 보정
- 상세 팝업에 "유형이 달라요/문 닫았어요" 1탭 제보 → 누적 시 유형 교정·비노출. 비용 하~중. 1안 출시 후 데이터 품질 지표(unknown 비율) 보고 결정.

### 3안(비추천 기록용): 카카오 로컬 실시간 검색 보조
- 저장 없이 화면 내 "세차장 즉석 검색" 버튼으로만 제공. 약관 안전하지만 우리 DB 레이어(1안)가 있으면 사용자 가치 중복이 크고, 갭 메우기 효과도 불확실. 1안 커버리지 실전 검증 후 재고.

## 6. 미해결/리스크

1. **영업상태 부재(가설)**: CSV에 영업상태/폐업 컬럼이 없다. "영업 중만 수록"인지 원천(인허가 데이터 명세) 확인 필요 — 폐업소 표시는 사용자 신뢰 직결. 데이터기준일자가 1990년대인 행도 존재해 노후 행 필터 정책(예: 기준일자 하한) 검토 필요. 소관 문의처: 기후에너지환경부 수질수생태과 044-201-7067(데이터셋 페이지 기재).
2. **다운로드 엔드포인트 안정성**: `file.localdata.go.kr`는 localdata 포털 폐쇄 후 남은 파일서버이고, Referer 없이는 403(실측)인 비공식성 짙은 경로다. URL 변경·중단 리스크 → sync 실패 알림 + 마지막 성공 스냅샷 유지(테이블 전체 삭제-재삽입 금지, EV의 "미완 sync stale 정리 금지" 교훈 준수) 필수.
3. **세차유형 62% 미기재**: 정규화 후에도 unknown이 다수일 전망 → UI에서 "유형 미확인" 정직 표기 + 유형 필터는 "미확인 포함" 기본값 검토. 정확한 unknown 비율은 정규화 규칙 구현 후 실측.
4. **시도명 체계 불일치**: '전남광주통합특별시', '경상북도'(대구경북 통합 여부 불명) 등 2026 개편 명칭 — 기존 `stations.sido` 및 EV zcode 17개 체계(`lib/ev/client.ts:10`)와 매핑 표 필요. bbox 조회만 쓰면 시도 매핑 없이도 v1 동작은 가능.
5. **좌표 품질**: 채움률만 검증했고 이상치(0,0·위경도 뒤바뀜·주소-좌표 불일치)는 미검증 → 임포트 시 한반도 bbox(33~39N, 124~132E) 범위 밖 행 드랍 가드 권장.
6. **오피넷 부설 데이터와의 중복 표시**: 독립만 임포트해도 '주유소' 업종 오기재 행이 남을 수 있음 → 상호·좌표 근접(예: 50m) 중복 판정 로직은 v2로 미룸.
7. **카카오 약관 재확인**: devtalk 답변은 개별 사안 회신이므로, 3안을 실제 채택할 경우 데브톡 공식 문의로 우리 시나리오(저장 없는 실시간 표시)를 서면 확인받는 것이 안전.
