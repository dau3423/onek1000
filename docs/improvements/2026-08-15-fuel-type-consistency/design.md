## 화면 흐름 (사용자 진입 → 행동 → 결과)

### 흐름 A — 경유/LPG 사용자의 검색 (FR-1)
1. 홈 필터바에서 유종 선택(예: 경유 D047) — 기존 동작, 변경 없음.
2. 헤더 🔍 탭 → `/search` 진입. 검색 페이지는 `useMapStore().product`를 그대로 따른다(페이지 내 유종 전환 UI 없음 — plan Out 확정).
3. 2글자 이상 입력 → 결과 리스트 위에 **"가격은 경유 기준"** 캡션 1줄 + 각 행에 **경유 가격 + 유종 캡션 + 셀프 배지** 표시.
4. 해당 유종 가격이 없는 업소(LPG 전용 충전소를 휘발유 모드로 검색 등)도 행이 노출되며 가격 자리에 "가격 정보 없음".
5. 행 탭 → 상세 진입(기존 링크 그대로).

### 흐름 B — 상세에서 내 연료 추이 확인 + 주유기록 (FR-2)
1. 상세 진입 시 가격 추이 섹션이 `useMapStore().product`를 기본 탭으로 선택. 해당 유종 가격이 없으면 non-null 첫 유종(PRODUCT_ORDER 순)으로 폴백.
2. 섹션 제목이 `"{PRODUCT_LABEL[선택]} 30일 추이"`로 표시, 제목 아래(오른쪽 아님) 유종 탭 칩 렬.
3. 탭 전환 → 차트가 스켈레톤(기존 h-40 pulse) → 해당 유종 30일 데이터로 갱신 + 제목 라벨 동기 갱신. 차트 높이 고정(h-40)이라 레이아웃 점프 없음.
4. 하단 CTA "여기서 주유" 펼침 → 리터/금액 추정 캡션이 **"({선택 유종 라벨} 단가 ₩x/L 기준)"** 으로 표시되어 선택 유종 연동을 사용자가 인지.

### 흐름 C — 셀프만 보기 (FR-3)
1. 홈(gas 레이어) 필터바 스크롤 영역 EV 칩 오른쪽의 **"셀프" 토글 칩** 탭.
2. 활성(주황 채움) 즉시 지도 마커·회색 점·하단 시트가 셀프 업소만으로 좁혀짐(클라이언트 필터, 로딩 없음). 브랜드 필터와 AND 결합.
3. 다시 탭 → 해제, 전체 복원. 유종 전환·패닝·EV 왕복에도 상태 유지(EV 레이어에서는 칩 미노출).
4. 예외: 전국 TOP10 크라운 핀은 필터 미적용(그대로 표시) — 별도 안내 UI는 넣지 않음(§미해결-1).

│ ● ○○LPG충전소                  │  ← (버그) 휘발유 모드에선 아예 미노출

변경 후:
```
┌─────────────────────────────────┐
│ ←  [ 주유소 이름 또는 주소   ] │  헤더 (변경 없음)
├─────────────────────────────────┤
│ 가격은 경유 기준                │  ← (a) 유종 컨텍스트 캡션 1줄
│─────────────────────────────────│
│ ● GS 신논현셀프 [셀프]   경유  │  ← (b) 셀프 배지  (c) 유종 캡션
│   GS칼텍스 · 서울 강남구 …  ₩1,460 │      (d) 선택 유종 가격
│─────────────────────────────────│
│ ● ○○LPG충전소            경유  │  ← (e) 가격 없는 업소도 노출
│   E1 · 서울 성동구 …  가격 정보 없음 │
└─────────────────────────────────┘
```

요소 설명:
- **(a) 유종 컨텍스트 캡션**: 결과 리스트가 렌더될 때만 리스트 바로 위 1줄. 문구 `가격은 {PRODUCT_LABEL[product]} 기준`. B027일 때도 동일하게 노출(조건부 등장/퇴장이 더 혼란). 비인터랙티브 — 유종 변경은 홈에서만(plan Out). 클래스: `px-5 pt-3 pb-1 text-[11px] text-gray-500`.
- **(b) 셀프 배지**: 업소명 오른쪽 인라인. 상세 부가서비스 배지와 같은 에메랄드 계열로 "셀프=초록" 인식 통일하되, 리스트 밀도에 맞게 축소형: `ml-1 shrink-0 rounded bg-emerald-50 px-1 py-0.5 text-[10px] font-bold text-emerald-700 dark:bg-emerald-950 dark:text-emerald-300`. 이름이 길면 이름만 truncate되고 배지는 `shrink-0` 유지.
- **(c)+(d) 가격 블록**: 행 우측 정렬 2줄 스택 — 위: 유종 캡션(`text-[10px] text-gray-400 text-right`), 아래: 가격(기존 `text-sm font-extrabold text-gray-900` 그대로). 모든 행에 캡션이 붙으므로 "이 가격이 무슨 유종인지"가 행 단위로 자명(AC-1의 "경유 라벨").
- **(e) 가격 없음 행**: 이름·주소는 정상 톤 유지(업소 발견이 1차 목적 — 행 전체 흐림 금지), 가격 자리만 `가격 정보 없음`(`text-xs text-gray-500`, 굵기 없음). 정렬은 이름순 유지(plan 확정) — 가격 유무로 순서를 바꾸지 않는다.
- 행 터치 타깃: 기존 `py-3` + 2줄 콘텐츠로 ≥56px — 변경 없이 충족.

요소 설명:
- **(a) 섹션 제목**: 기존 클래스 유지(`mb-2 text-sm font-bold text-gray-800`), 텍스트만 `{PRODUCT_LABEL[selected]} 30일 추이`.
- **(b) 유종 탭**: 제목 아래 가로 칩 렬(좁은 화면 대비 `flex flex-wrap gap-2` 또는 `overflow-x-auto` — 최대 4개라 wrap 권장). FilterBar 칩 스타일 재사용:
  - 활성: `rounded-full bg-primary px-3.5 py-2 text-xs font-semibold text-white`
  - 비활성: `rounded-full bg-gray-100 px-3.5 py-2 text-xs font-semibold text-gray-700 hover:bg-gray-200 dark:bg-gray-800 dark:text-gray-300 dark:hover:bg-gray-700`
  - `py-2`(높이 약 36px) + `gap-2` + 섹션 상하 여백으로 실효 터치 영역 44px 확보(FilterBar 칩 `py-1.5`보다 한 단계 키움 — 지도 오버레이 제약이 없는 일반 문서 흐름이므로).
  - 시맨틱: `role="tablist"` + 각 칩 `role="tab"` `aria-selected` (`aria-controls`→차트 영역 `role="tabpanel"`). 라벨은 `PRODUCT_LABEL` 텍스트(아이콘 없음).
  - 노출 규칙: `detail.prices`에서 non-null 유종만 `PRODUCT_ORDER` 순. **1개뿐이면 탭 렬 자체를 렌더하지 않음**(제목 라벨만 그 유종). **전부 null이면** 현행 유지 — 제목 "휘발유 30일 추이" + B027 차트(빈 데이터 문구는 차트 기존 "아직 가격 이력이 충분하지 않아요").
- **(c) 차트**: `PriceHistoryChart` 그대로(변경 없음). 탭 전환 시 자체 스켈레톤(h-40 pulse) → 데이터. 높이 고정으로 CLS 없음.
- **(d) 주유기록 추정 캡션**: `FuelLogButton` 추정 문구의 하드코딩 "(휘발유 단가 …)"를 `({productLabel} 단가 ₩x/L 기준)`으로 — 선택 유종 라벨을 prop으로 수신. CTA 버튼 자체의 텍스트/스타일/위치는 불변.
- **섹션 순서 불변(디자인 요구)**: 현행 시각 순서(내 주유 기록 → 추이 → 리뷰 → 부가서비스 → CTA)를 유지할 것. plan의 상태 공유 옵션 중 (a) "래퍼가 두 섹션을 함께 렌더 + 순서 재배치"를 택하더라도 **DOM/시각 순서가 바뀌면 안 됨** — 컨텍스트 프로바이더로 서버 섹션들을 children으로 감싸는 방식 등, 순서를 보존하는 구현을 권장(§미해결-2).

- 스타일: EV/유종 칩과 100% 동일 토큰 — `shrink-0 rounded-full px-3 py-1.5 text-xs font-semibold transition`, 활성 `bg-primary text-white`, 비활성 `bg-gray-100 text-gray-700 hover:bg-gray-200 dark:bg-gray-800 dark:text-gray-300 dark:hover:bg-gray-700`.
- 라벨: 텍스트 "셀프"(아이콘 없음 — 기존 유종 칩과 동일한 텍스트 칩). `aria-pressed={selfOnly}`.
- 동작: 탭=토글, 즉시 클라이언트 필터 반영(스피너 없음). 유종 칩과 달리 **선택해도 다른 칩을 해제하지 않음**(유종+셀프 동시 활성 = 주황 칩 2개 공존이 정상 — QA 참고).
- 터치: 필터바는 지도 상단 고정 오버레이라 기존 칩 크기(높이 약 30px)를 유지하되, 칩 간 `gap-1.5` + 바 `py-2`로 실효 터치 영역을 확보(기존 칩들과 동일한 기존 관례 준수 — 칩 하나만 커지면 정렬이 깨짐).

## 스타일 지침

- **색/토큰**: 새 hex 도입 금지. primary(#FF6B00)는 기존 `bg-primary`/`text-primary` 유틸로만. 회색조는 각 페이지가 이미 쓰는 단계(gray-100/400/500/700/900)만 사용. 셀프 배지는 emerald-50/700(+dark 변형)으로 상세 AmenityList와 동일 계열.
- **다크모드(NFR-8 갭 대응 최소 원칙)**: 검색·상세 페이지는 현재 라이트 전용(`dark:` 부재)이며 다크 정합은 별도 백로그 주제다. 이번 신규 요소는:
  1. 이 페이지들의 기존 라이트 톤과 동일한 **시맨틱 Tailwind 클래스**(bg-gray-100, text-gray-500 등)만 사용해 향후 일괄 `dark:` 패스가 가능하게 한다(인라인 style·raw hex 금지).
  2. **원본에 이미 dark: 쌍이 있는 스타일을 복제하는 경우 dark: 쌍까지 함께 복제**한다 — FR-2 탭·FR-3 칩(FilterBar 칩의 `dark:bg-gray-800 dark:text-gray-300 dark:hover:bg-gray-700`), 셀프 배지(AmenityList의 `dark:bg-emerald-950 dark:text-emerald-300`). 라이트 페이지에선 무해하고, 다크 도입 시 공짜로 정합된다.
  3. 향후 다크 도입 시 보정 지점 메모: 검색 유종 캡션/가격 없음 텍스트(text-gray-400/500), 검색 행 hover(bg-gray-50), 상세 섹션 제목(text-gray-800), 추이 탭 비활성 배경. 차트 축/그리드 색(`#eee`, `#9ca3af`)은 기존 하드코딩 — 이번 범위에서 손대지 않음.
- **모바일**: `max-w-md` 단일 컬럼 유지. 상세 CTA 섹션의 `pb-[calc(16px+env(safe-area-inset-bottom))]` 불변. 검색 행 ≥56px, 상세 탭 실효 44px(칩 36px + 여백), 필터바 칩은 기존 크기 관례 유지. 탭·칩은 엄지 도달 범위의 가로 나열, 스크롤 필요 시 `overflow-x-auto`(스크롤바 숨김은 기존 필터바 관례 따름).
- **접근성**: 모든 신규 인터랙션 요소는 텍스트 라벨(아이콘 단독 금지). FR-2 탭 `role="tablist"/"tab"` + `aria-selected`, FR-3 칩 `aria-pressed`. 활성 상태는 색 + 굵기(font-semibold, 흰 글자)로 색약자도 구분 가능(주황 채움 vs 회색 채움은 명도 차 큼). 본문 필수 정보("가격 정보 없음")는 gray-500 이상 유지(gray-400은 보조 캡션 한정).

## 미해결/리스크

1. **TOP10 크라운 핀 셀프 미적용 혼란(plan 미해결-3)** — 디자인 결정: **지도 위 추가 안내 UI를 넣지 않는다.** 크라운 핀은 이미 일반 가격 마커와 시각적으로 구분되는 별도 계층(전국 TOP10)이고, 지도 오버레이에 예외 설명 텍스트를 얹는 것은 소음이 더 크다. 대응: (i) QA 시나리오에 S14를 예외로 명시, (ii) 근본 해결은 백로그의 `NationalTop10Item.isSelf` 확장으로 — 그때 크라운 핀도 동일 필터에 편입하면 안내 불필요. 사용자 혼란 신고가 실제 발생하면 크라운 핀 팝업(StationPopup) 내 "전국 TOP10은 필터와 무관하게 표시돼요" 캡션 1줄을 후보로 재검토.
2. **FuelLogButton 상태 공유 방식에 따른 레이아웃 회귀(plan 미해결-4)** — 디자인 요구로 **섹션 시각 순서 불변**을 고정했다(FR-2 와이어프레임). 구현이 옵션 (a)(래퍼 확장)를 택할 경우 리뷰·부가서비스 섹션이 클라이언트 래퍼의 children으로 들어가야 순서가 보존됨 — 순서가 바뀌는 구현은 반려 기준. QA 체크: 모바일 뷰포트에서 상세 페이지 섹션 순서·`mt-auto` CTA 하단 고정·safe-area 패딩 회귀 확인.
3. **검색 페이지 유종 전환 UI 부재의 잔여 마찰** — "가격은 경유 기준" 캡션으로 상태는 인지시키지만, 검색 중 유종을 바꾸려면 홈으로 돌아가야 한다. plan Out(백로그) 확정을 따르되, 캡션 문구가 탭 유도로 오인되지 않게 비인터랙티브 스타일(회색 소형 텍스트, 밑줄·아이콘 없음)을 지킬 것.
4. **터치 타깃 44px 기준의 부분 타협** — 필터바 셀프 칩은 기존 칩 크기(약 30px)를 따른다(오버레이 밀도·기존 칩과의 정렬 우선). 상세 추이 탭은 44px 실효 확보. 필터바 전체 칩 크기 상향은 별도 접근성 개선 주제로 백로그 메모.
5. **검색 오류/오프라인 상태 화면 부재(기존 결함 승계)** — fetch 실패 시 현재도 빈 결과처럼 보인다. 이번 범위(유종 일관성)에 포함하지 않고 현행 유지 — 검색 UX 재설계 백로그와 함께 다룰 것.
6. **다크모드 정합은 미완(NFR-8 갭)** — 이번 신규 요소는 "시맨틱 클래스 + 원본에 있던 dark: 쌍 복제"까지만 보장한다. 검색·상세 페이지 전체의 다크 패스는 별도 백로그(보정 지점 목록은 §스타일 지침 참조).
7. **plan FR 커버리지**: FR-1(흐름 A·S1~S5), FR-2(흐름 B·S6~S10), FR-3(흐름 C·S11~S14) 모두 반영 — 미반영 FR 없음. 단 FR-1 AC-5(400 응답)·API 파라미터 검증은 서버 계약 영역으로 화면 명세 대상 아님(구현 단계 소관).
